# Regulariza Brasil Empresarial

Landing page estática para captação de leads de regularização fiscal, administrativa e regulatória.

## Publicação

Arquivo principal: `index.html`.

Sugestão para deixar online pelo GitHub Pages:

1. Acessar **Settings** do repositório.
2. Entrar em **Pages**.
3. Em **Build and deployment**, selecionar **Deploy from a branch**.
4. Escolher branch `main` e pasta `/root`.
5. Salvar.

URL esperada após ativação:

`https://drjfalcao-bot.github.io/oabsimula/`
